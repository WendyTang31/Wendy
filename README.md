# Wendy Tang Design Portfolio

A frontend-only portfolio shell for design work at the intersection of design,
engineering, robotics, biomimicry, and research.

## Stack

- React
- TypeScript
- Tailwind CSS
- Vite
- Vercel-ready static build
- Cloudinary-ready image slots

## Getting started

```bash
npm install
npm run dev
```

## Available scripts

- `npm run dev` - start the local development server
- `npm run build` - type-check and build the production site
- `npm run preview` - preview the production build locally
